# FireHearts ❤️‍🔥 - Trova la tua scintilla

App dating premium con Fire Score basato su feedback reali. Costruita in React Native + Expo.

## 🚀 Live Demo
`npx expo start` → premi `w` per Chrome

## ✨ Features

### Giorno 1 - Base
- Card profilo con overlay 85px (foto sempre visibile)
- Filtri città
- Tab Scopri / Inviate / Match / Profilo
- Chat base

- **Flip ovunque**: tap foto → Bio completa, tap ovunque sulla bio → foto
